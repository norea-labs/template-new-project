# Knowledge del progetto

Qui sta tutto quello che serve sapere su questo progetto e che non si legge dal codice: decisioni, funzionamento, integrazioni, accordi con il cliente.

- Un file per argomento, testi brevi, in italiano.
- Si aggiorna insieme al codice: ogni modifica che cambia come funziona il progetto aggiorna anche il file giusto qui.
- Niente segreti e niente dati di produzione o dei clienti: i segreti stanno in 1Password.

Se il progetto tiene la knowledge in un altro path, va scritto nel `CLAUDE.md`, sezione "Questo progetto".
